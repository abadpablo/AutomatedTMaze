# AutomatedTMaze

Welcome to the AutomatedTMaze repository !! This is a repository for having all the necessary elements for building an automated TMaze (3D print files and PCB files).

In the Blender files folder you can find the original Blender files in case you want to edit them.

In the Stl files folder you can find the STL files ready for printing in a filament 3D printer machine.

In the Autodesk fusion files you can find the Eagle/Autodesk fusion files. Inside it there is a .zip folder ("Maze.zip") that is the one you want to upload into the PCBway webpage (https://www.pcbway.es/) for fabrication.

## Components

1. Arduino Nano
2. 100 uF capacitor (x7)
3. Servomotor (x5)
4. PCB screw terminals 2 pins (x5)
5. PCB screw terminals 3 pins (x9)
6. PCB screw terminals 4 pins (x1)
7. Mosfet N-terminal IRF520N (x2)
